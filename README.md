# Github-App-Installer
App i made to install Git related apps and a few more (like pwsh, UniGetUi, VSCode, and Node.js)</br>
<hr>
Github App Installer.hta (any edition) uses buttons to choose apps to install, and the .vbs installs all apps when opened automatically. I don't know about the .js, but it should work the same.
